# この病院のルール（問診票を読み取るときに Claude に守らせること）

病院ごとに書き換えてください。1行に1つ、ふつうの日本語で書けます。

## 聞かない欄（設問にしない）
- 氏名・フリガナ・生年月日・住所・電話番号・記入日は聞かない（患者IDで電子カルテとひも付くため）。
- 受付番号・ID・氏名など、職員が書く欄は聞かない。
- 新型コロナウイルスに関する欄（陽性者との接触、ワクチン接種）は聞かない。
- 12歳以下の体重など、子ども向けの欄は聞かない。
- 病院名、案内文（「紹介状をお持ちの方はお出しください」など）、制度の説明文は設問にしない。

## 残す欄
- マイナ保険証による診療情報取得の同意は、紙にあれば設問として残す。

## 年齢・性別と妊娠・授乳
- 年齢・性別の欄が紙にあれば設問にする。id は年齢が `age`、性別が `sex`。性別の選択肢は「男性」「女性」。年齢は数値で単位は「歳」。
- 年齢と性別は、問診のはじめのほうに置く。
- 妊娠・授乳の設問は、「性別が男性ではない」かつ「年齢が50歳未満」のときだけ出す
  （show_if に `q=sex, op=ne, value=男性` と `q=age, op=lt, value=50` の2つを入れる）。

## 決まった選択肢（どの問診票でも同じ言い方にそろえる）
紙では書く欄になっていても、次の内容は選ぶ形（single または multi）にする。紙にない選択肢なので added を true にする。

- 症状が「いつごろから」あるか（single）：
  今日から／昨日から／2〜3日前から／1週間くらい前から／2〜3週間前から／1か月くらい前から／2〜3か月前から／半年くらい前から／1年以上前から／わからない
- 体温が高かった日など、最近の「いつ」（single）：
  今日／昨日／おととい／3日以上前／わからない
- 症状が「何時ごろから」始まったか（single）：
  朝／昼／夕方／夜／夜中／わからない
  この設問は、「いつごろから」で「今日から」か「昨日から」を選んだときだけ出す
  （show_if に2つの条件を入れ、show_if_mode を any にする）。
- 学年（single）：
  小学1年／小学2年／小学3年／小学4年／小学5年／小学6年／中学1年／中学2年／中学3年／高校1年／高校2年／高校3年／大学・専門学校
- 部活（single）：
  野球／サッカー／バスケットボール／バレーボール／テニス／卓球／陸上／水泳／柔道・剣道／文化部／していない／その他
- けが・痛みの「思い当たる原因」（multi。紙に選択肢があれば、それも同じ設問に入れる）：
  転んだ／ぶつけた／ひねった／重い物を持った／スポーツ中／仕事中／交通事故／同じ動作のくり返し／思い当たらない／その他

## 言い方
- 「最高の体温」は、「今回の症状が出てから、いちばん高かった体温を教えてください。」と聞く
  （生まれてからの最高と読まれないようにする）。
- 「現在、病院に通院されていますか」は、紙の言い方のまま聞く。当院の別の科への通院はカルテで分かるので、
  「ほかの病院に」という言いかえがあっても指摘しなくてよい。

## 学生の方の欄
- 「学生の方　学年（　）部活（　）」のような欄のために、「学生ですか？」という設問を足さない。
  学年の設問文を「学生の方は、学年を教えてください。」とし、選択肢の先頭に「学生ではない」を置く。
  部活の設問は、学年で「学生ではない」を選んでいないときだけ出す。

## 体の図
- 「症状のある部位を図で示してください」のように体の図に印をつける欄は、type を `body` にする（人体シェーマの画面になる）。
