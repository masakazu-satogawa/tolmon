# この病院のルール（問診票を読み取るときに Claude に守らせること）

病院ごとに書き換えてください。1行に1つ、ふつうの日本語で書けます。

## 聞かない欄（設問にしない）
- 氏名・フリガナ・生年月日・住所・電話番号・記入日は聞かない（患者IDで電子カルテとひも付くため）。
- 受付番号・ID・氏名など、職員が書く欄は聞かない。
- 新型コロナウイルスに関する欄（陽性者との接触、ワクチン接種）は聞かない。
- 12歳以下の体重など、子ども向けの欄は聞かない。
- 病院名、案内文（「紹介状をお持ちの方はお出しください」など）、制度の説明文は設問にしない。

## 残す欄
- マイナ保険証による診療情報取得の同意は、紙にあれば設問として残す。

## 年齢・性別と妊娠・授乳
- 年齢・性別の欄が紙にあれば設問にする。id は年齢が `age`、性別が `sex`。性別の選択肢は「男性」「女性」。年齢は数値で単位は「歳」。
- 年齢と性別は、問診のはじめのほうに置く。
- 妊娠・授乳の設問は、「性別が男性ではない」かつ「年齢が50歳未満」のときだけ出す
  （show_if に `q=sex, op=ne, value=男性` と `q=age, op=lt, value=50` の2つを入れる）。

## 体の図
- 「症状のある部位を図で示してください」のように体の図に印をつける欄は、type を `body` にする（人体シェーマの画面になる）。
