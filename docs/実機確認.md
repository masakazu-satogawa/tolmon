# 実機（iPad・Android タブレット）で確かめる手順

PC のブラウザでは確かめてありますが、タブレットの実機ではまだ確かめていません。
この手順は、PC で動かしているトルモンを、同じ Wi-Fi のタブレットから開いて確かめるためのものです。
入れるのは架空の回答だけにしてください（本物の患者さんの情報は入れません）。

## 用意するもの

- トルモンを動かす PC（Python 3.13）
- タブレット（iPad は Safari、Android は Chrome）
- PC とタブレットの両方がつながる Wi-Fi

**病院の業務用のネットワークでは試さないでください。** 自宅の Wi-Fi か、スマートフォンのテザリングを使います。

## 手順

1. PC とタブレットを、同じ Wi-Fi につなぎます。
2. ふだんの黒い画面（`start.bat`）が開いていたら、閉じます。
3. `start_tablet.bat` をダブルクリックします。
   - はじめての時、Windows が「このアプリの機能のいくつかがファイアウォールでブロックされています」と聞いてくることがあります。
     自宅の Wi-Fi なら「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」を押します。
     （この画面が出ず、タブレットからつながらないときは、下の「つながらないとき」を見てください。）
4. 黒い画面に、次のような行が出ます。この URL を、タブレットのブラウザに打ちます。

   ```
   ── ほかの端末（タブレット）から開くとき ──
   　タブレットのブラウザに、これを打ちます →  http://（数字）:8080/
   ```

   数字は Wi-Fi によって違います（`192.168.` や `10.` で始まります）。`http://` から、黒い画面のとおりに打ってください。

5. タブレットに「診療科を選んで、タブレットをお渡しください」と出れば、つながっています。
6. 下のチェック表を、上から順に試します。
7. 終わったら、黒い画面を閉じます（これで、ほかの端末からは開けなくなります）。
   試しに入れた回答は、`demo_reset.bat` で片づけられます（消さずに `data/backup/` へ移します）。

「作る画面」（`/admin`）は、Claude の APIキーを使うので、タブレットからは開けないようにしてあります。PC からだけ開けます。

### あると助かる確認

- ホーム画面に追加して開く（iPad：共有 →「ホーム画面に追加」）。アドレスの欄が消えて、画面が広く使えるか。
- 古い機種（iPad 第7世代）での動きの速さ。体の図の切り替えで待たされないか。
- 指ではなく、タッチペンや爪で押したときの反応。

## つながらないとき

- **タブレットに何も出ない**：PC とタブレットが同じ Wi-Fi か、確かめます（来客用の Wi-Fi は、端末どうしがつながらない設定のことがあります）。
- **タブレットの Wi-Fi が PC と違う**：タブレットの設定で、Wi-Fi の名前が PC と同じか確かめます。
  タブレットの IPアドレス（Wi-Fi の名前の横の ⓘ）の先頭が、黒い画面の数字の先頭と同じなら、同じ Wi-Fi です。
- **同じ Wi-Fi なのにつながらない**：職場や施設の Wi-Fi は、端末どうしをつながせない設定になっていることがあります。
  スマートフォンのテザリングに PC とタブレットの両方をつなぎ、`start_tablet.bat` を開き直してください（アドレスが変わります）。
- **それでもつながらない**：Windows のファイアウォールが止めています。
  会社や病院が管理している PC では、自分では許可できないことがあります。そのときは無理に設定を変えず、
  別の PC（自宅の PC など）にこのフォルダをコピーして試してください。フォルダごとコピーすれば動きます。
- **`http://` を付け忘れると、検索になってしまう**ことがあります。`http://` から打ってください。
